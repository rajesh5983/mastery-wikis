## How to Use This Wiki

1. Capture articles and ideas in `_inbox.md` as they arrive
2. Use `_this-week.md` to plan focused study sessions
3. Every concept note follows the template in `_templates/topic-note.md`
4. Cross-reference related concepts using `[[wikilinks]]`
5. Update the Status field in each concept as you gain mastery
6. Promote ⬜ concepts to 🔴, 🟡, then 🟢 over time
